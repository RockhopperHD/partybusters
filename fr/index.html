      Comment Jouer

      Votre but est d'ADMETTRE ou REFUSER correctement les invités selon les règles du niveau.

      Écoutez ce que dit l'invité. Ouvrez le tableau des règles (survolez 'RÈGLES') pour voir les règles. Pour CHAQUE règle, décidez si l'invité la Suit (✅) ou l'Enfreint (❌) en utilisant les boutons.

      Vous devez évaluer TOUTES les règles avant de décider. Une fois terminé, les boutons Admettre et Refuser seront activés sur le tableau.

      Cliquez sur Admettre si l'invité suit TOUTES les règles (vous avez marqué ✅ pour toutes). Cliquez sur Refuser s'il enfreint N'IMPORTE QUELLE règle (vous avez marqué ❌ pour au moins une).

      Les bonnes décisions rapportent des points et vous rapprochent de l'objectif. Les mauvaises décisions coûtent une vie (❤️). Manquer de temps coûte aussi une vie.

      À la fin du niveau, le représentant peut vous poser une question rapide d'exercice. Répondez-y pour continuer !
